0. How to use this pack

This pack contains three kinds of prompts. Use them in this order.

The Master Rules Prompt (Section 1) — paste this ONCE at the start of your Antigravity project, or save it as your project rules file (AGENTS.md / .agentrules / project instructions, depending on where Antigravity stores them). It stays active for the whole build. Do not re-paste it every message.

Phase Prompts (Section 3) — paste ONE phase prompt per session. Never paste two phases at once. Wait until the phase is verified working before moving to the next.

Recovery Prompts (Section 4) — paste these when the agent misbehaves: loops, over-engineers, invents things, or burns credits.

Golden rule for credit safety: one phase = one session = one clearly bounded deliverable. If a session goes past roughly 20 agent turns without producing a runnable result, stop it, open a new session, and use a Recovery Prompt.
