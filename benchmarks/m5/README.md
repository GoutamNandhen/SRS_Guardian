# M5 benchmark artifacts

`controlled_pilot_results.json` is generated by `python -m backend.evaluation.m5_controlled_pilot --out benchmarks/m5/controlled_pilot_results.json`.

Its 20 examples are synthetic variants of a **single requirement family**. They are *not* 20 real software projects or independently annotated examples. See `docs/research/M5_BENCHMARK_AND_ACCURACY.md` before reporting any scores.

Expected independent-label data for future Track B uses the M1 `gold.jsonl` and `predictions.jsonl` schema, plus separate data provenance fields. Do not put confidential third-party repository code or unlicensed dataset copies in this repository.
